# 小红书技术类图文素材库（去广告版）

从小红书采集的软件开发 / 技术 / 爬虫类博主内容，按「图文完整 + 无广告营销」两个条件筛选后，可直接复制发布的素材。

## 内容规模

- 采集范围：1,144 位技术类博主，53,968 条笔记索引
- 本次收录：**26 条**，全部为图文完整、且不含广告营销卖课内容的技术帖
- 已剔除：34 条（外包报价、软件公司自宣、少儿编程机构招生、卖课卖书、学习笔记引流）

## 分组

| 目录 | 内容 | 数量 |
|---|---|---|
| `01-大模型与AI` | Transformer 架构、RL 算法、Agent、AI 编程入门 | 7 |
| `02-开发与代码` | 代码质量、面试八股、工作流、实战 | 8 |
| `03-前端与学习路线` | 前端学习路径、自学方法、职业经验 | 4 |
| `04-Python每日一题` | Python 小题与解析 | 7 |

## 每个帖子目录里有什么

```
016-howto Github 零基础终极教程/
├── 正文.md            排版版：标题、互动数据、正文、话题标签、图片清单
├── 正文-纯文本.txt     可直接全选复制，粘贴到发布框
└── 图片/
    ├── 01.jpg         按序发布
    └── 02.jpg
```

## 怎么用

1. 打开任意帖子目录
2. 双击 `正文-纯文本.txt`，全选复制
3. 把 `图片/` 里的 jpg 按 01、02 顺序拖进发布框

## 筛选标准

**收录**：有实质技术内容、正文可读、图片是内容图或可用的教程封面。

**剔除**（共 34 条）：

- 外包/接单广告：报价、定制开发、多少钱、找靠谱团队
- 软件公司自宣：交付案例、项目上线、客户好评
- 少儿编程机构：考级证书、招生、比赛案例、选机构
- 卖课卖书：教材出版、康复课程、学习笔记引流

## 数据来源与局限

小红书网页端对图文笔记只返回封面图，因此只有「多图纯文字系列」能拿到完整内容。大量单图笔记抓到的只是黑底标题卡、人像海报或视频截图，不具备发布价值，未收录。
