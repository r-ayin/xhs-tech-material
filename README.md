# 小红书技术类图文素材库

从小红书采集的软件开发 / 技术 / 爬虫类博主内容，按「图片 + 文字完整度」筛选后可直接复制发布的素材。

## 内容规模

- 采集范围：1,144 位技术类博主，53,968 条笔记索引
- 拿到完整图文的：60 条
- 分档：
  - `01-教程干货` 8 条 — 真正的技术教程，推荐优先使用
  - `02-外包营销` 12 条 — 小程序/APP 开发报价类，内容完整但性质是服务商广告
  - `03-其他完整` 40 条 — 职场、育儿编程、生活类，与技术关联较弱

## 每个帖子目录里有什么

```
302-终于有人把小程序开发流程讲明白了/
├── 正文.md            排版版：标题、互动数据、正文、话题标签、图片清单
├── 正文-纯文本.txt     可直接全选复制，粘贴到发布框
└── 图片/
    ├── 01.jpg         按序发布
    └── 02.jpg
```

## 怎么用

1. 打开任意帖子目录
2. 双击 `正文-纯文本.txt`，全选复制
3. 把 `图片/` 里的 jpg 按 01、02 顺序拖进发布框

## 数据来源与局限

**重要**：小红书网页端对图文笔记只返回封面图。也就是说，只有「多图纯文字系列」这类笔记能拿到完整内容；大量单图笔记抓到的只是黑底标题卡、人像海报或视频截图，不具备发布价值，已全部剔除，不在本仓库内。

因此本仓库只收录 60 条确认图文完整的笔记。另外 175 条技术类笔记因只有封面被排除，4.9 万条仅有标题和点赞数、无正文图片。

## 索引

`index.csv` 列出全部 60 条：分组、文件夹、标题、有效正文字数、图片数。
